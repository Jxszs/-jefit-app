# 💪 JEFIT APP

**Tu app de gym con estilo Symmetry + Cbum.**
Dark aesthetic, rank system y check-in gamification.

## Stack
- **Frontend**: Flutter (Android + iOS)
- **Backend**: Node.js + Express
- **Algorithms**: Python (rank calculation)
- **Database**: MongoDB

## Estructura
```
jefit-app/
├── frontend/          # Flutter app
├── backend/            # Node.js API
├── algorithms/         # Python rank calculator
└── docs/               # Documentation
```

## Desarrollo
```bash
# Frontend
cd frontend && flutter run

# Backend
cd backend && npm install && npm run dev

# Algorithms
cd algorithms && pip install -r requirements.txt
```
