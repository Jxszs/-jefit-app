# POLÍTICA DE PRIVACIDAD - JEFIT APP

**Última actualización:** __/__/____

## 1. Datos Personales Tratados
- **Identificación**: nombre, email
- **Datos de uso**: logs de entrenamiento, reps, cargas, ejercicios
- **Datos biométricos**: peso corporal, medidas, fotos before/after
- **Datos de comunicación**: mensajes con entrenadores
- **Datos de dispositivo**: modelo, sistema operativo, IP

## 2. Finalidad del Tratamiento
| Dato | Finalidad |
|---|---|
| Nombre/email | Crear y gestionar tu cuenta |
| Logs de entrenamiento | Tracking de progreso |
| Fotos before/after | Transformación visual |
| Mensajes | Comunicación con entrenadores |

## 3. Base Legal
- **Consentimiento**: fotos, mensajes, notificaciones
- **Ejecución contrato**: cuenta, tracking, rankings
- **Legítimo interés**: analytics anónimos

## 4. Derechos (Ley 19.628 + GDPR)
- Acceder, rectificar, suprimir tus datos
- Portabilidad: exporta tus datos desde Settings > Exportar
- Revocar consentimiento: Settings > Privacidad
- Solicitar borrado: contacto@jefit-app.com

## 5. Terceros
- **Supabase** (EE.UU.): hosting de base de datos → cláusulas contractuales de privacidad
- **Google/Apple**: pagos de suscripción
- **Sentry**: crash reporting (anónimo)

## 6. Retención
- Datos de cuenta: mientras la cuenta esté activa
- Logs de entrenamiento: 5 años
- Fotos: hasta 30 días después de borrado (backup)

## 7. Seguridad
- Encriptación AES-256 en base de datos
- JWT + HTTPS para todas las comunicaciones
- 2FA opcional para cuentas premium
